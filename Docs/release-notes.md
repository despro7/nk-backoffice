# «Що нового» і версії

Короткий список змін для користувачів (простою українською) та автоматичне підняття версії перед деплоєм. Технічний журнал лишається в `Docs/CHANGELOG.md`.

## Дані: `shared/releaseNotes.json`

```json
{
  "unreleased": [{ "type": "new", "text": "…", "permission": "page.reports.sales" }],
  "releases": [{ "version": "1.3.1", "date": "2026-11-26", "items": [] }]
}
```

- `type`: `new` («Нове»), `improved` («Покращено»), `fixed` («Виправлено»).
- `text`: одне просте речення без назв файлів, ендпоінтів і жаргону.
- `permission` (необовʼязково): ключ права з `shared/constants/permissions.ts`. Користувач без права пункт не бачить; реліз без видимих пунктів приховано. Враховується перегляд ролі адміністратором.
- `releases`: від нових до старих.

Типи: `shared/types/releaseNotes.ts`. Перевірка: `scripts/release-notes-lib.cjs` (тести `scripts/release.spec.ts`).

## Як додавати

Кожна помітна користувачу зміна: 1–2 пункти в `unreleased` разом із записом у CHANGELOG. Внутрішні зміни, рефакторинг і деплой не додаються.

Тексти погоджує користувач: перед додаванням пунктів в `unreleased` покажіть точний текст (`type`, формулювання, за потреби `permission`) і дочекайтесь схвалення або правок. Пропонуйте їх разом із записом CHANGELOG під час підготовки коміту.

## Випуск версії

```bash
npm run release -- --dry-run
```

```bash
npm run release
```

- Порожній `unreleased`: помилка.
- Є пункт `new`: minor (`1.3.1` → `1.4.0`), інакше patch (`1.3.2`).
- `--major`: `X+1.0.0`, лише за окремим рішенням.
- Переносить пункти в `releases` з сьогоднішньою датою (Київ), оновлює `package.json` і `package-lock.json`, робить коміт `chore(release): vX.Y.Z` лише цих трьох файлів і анотований тег `vX.Y.Z`.
- Відмовляється працювати, якщо в цих файлах є незакомічені зміни або щось уже додано в індекс.

## Деплой

`npm run deploy` після перевірок (гілка, чисте дерево, `master` запушений) питає, чи випустити версію, якщо `unreleased` не порожній (`--yes`: без питання), і робить `git push --follow-tags`. Відмова: деплой триває, а пункти чекають наступного релізу. На сервері `npm ci` не запускається, якщо в `package-lock.json` змінилась лише версія застосунку.

## UI

- Рядок «Що нового» з версією внизу бічного меню (`client/components/whats-new/`).
- Остання переглянута версія: `localStorage.whatsNewLastSeenVersion`. Після оновлення з новими доступними пунктами вікно відкривається саме, до закриття горить крапка. Перший візит: версія запамʼятовується без показу.
- Банер оновлення: «Що змінилось» показує релізи нового білду з `public/version.json` (`version`, `hash`, `builtAt`, останні 5 `releases`; пише `scripts/generate-version.cjs`).
